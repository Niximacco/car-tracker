Paste a spreadsheet

Download the sheet as csv, or select the cells and copy them. The first line has to be the column headings. It needs a date column and an odometer column; from there, a row with gallons on it is a fill-up and a row with work on it is a visit to the shop. Columns it does not recognize - the mpg, the running total, anything this site calculates for itself - are ignored rather than complained about.

The original spreadsheet

Four years of the Google Sheet this site replaces - {{count .SeedFillups}} fill-ups and {{count .SeedServices}} shop visits - are compiled into this service, so the very first import does not need an export at all. It goes through the same reader a paste does, and lands on the same confirm screen.

It is safe to run more than once: each entry is stored under its date and reading, so a second run writes over the same rows.
